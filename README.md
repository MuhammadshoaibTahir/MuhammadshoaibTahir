## 🚀 Featured Projects

### 🧠 Corpus-Driven Intelligence System (SmartSearch)
A natural-language interface for corpus exploration that converts user questions into  
**executable corpus queries** (frequency, concordance, collocations, statistics)  
with **zero hallucination**.

**Key idea:** Answers are computed strictly from corpus evidence, not generated text.
